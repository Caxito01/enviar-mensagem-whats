# Gerador de Link WhatsApp - Versão Desktop

Este projeto pode ser executado como aplicativo desktop usando Electron.

## Como rodar como aplicativo desktop

1. Instale as dependências (se ainda não fez):

```powershell
npm install
```

2. Execute o aplicativo desktop:

```powershell
npm run desktop
```

O aplicativo abrirá em uma janela própria, sem precisar de navegador.

---

Se quiser gerar um instalador (.exe), me avise que posso configurar o empacotamento para Windows.
